# 对话、旁听与主动表达

目标：让大肥鱼作为有稳定语气的聊天角色参与对话，而非养成游戏。人设由 [`persona.toml`](../../config/persona.toml) 定义；本文只记录程序行为，不把提示词中的语气要求写成确定性保证。

## 接收与直接回复

- 私聊，或飞书 mention 元数据明确指向 bot 的群消息，属于直接对话；仅出现角色名字不等于 @。其他成员的 mention 保留为内容，不冒充 bot 指令。
- 首次直接对话创建会话；非直接消息仅在已有会话中旁听。支持文本、富文本和图片描述；不支持的消息类型或空文本有降级回复；畸形事件可能直接忽略。
- 同会话直接消息防抖合批并串行回复；生成上下文包含说话人、近期原文、召回记忆和适用风格示例。风格检索与人物路由/记忆召回并行，召回仍使用路由结果；任一失败会取消另一项并走降级回复。
- 说话人称呼使用群成员接口的飞书展示名（按群缓存 10 分钟，获取失败同样缓存），只用于称呼；私聊不查询。冷缓存查询总共最多等待 0.5 秒；拿不到名字时标为“名字未知”，提示模型用“你”等自然称呼，不念编号或 ID。
- 需要生成的直接消息在批次开始处理时加上 `reply.processing_reaction` 表情（默认 `Typing`），回复发送、生成失败或投递失败后在后台移除，不占用会话锁；添加、删除表情各最多等待 2 秒，失败只记日志。旁听和降级回复不加表情。表情接口超时或进程退出可能留下未移除的表情。
- Gemini 原生接入的直接回复提供 Google Search 工具，由模型按需决定是否搜索；提示词要求实时信息或明确的联网请求先搜索，来源链接放入 reply 正文，仍使用 JSON 回复契约。搜索可能产生额外费用与延迟，提示词不保证每次都正确触发搜索。主动发言、记忆压缩、梗图审核与图片处理不启用搜索；OpenAI-compatible 接入不提供此工具。
- 推理/纠正风格不再要求命中特定关键词；语义候选可以入选，明确不想听建议和身体/调侃对象保护仍保留。
- 风格语料是表达参考，不是当前事实或用户指令；索引不可用时可退回词法匹配。近期已用示例的避让只在发送成功后更新。

## 旁听与自动发言

- 旁听先缓冲，再批量写入；可能触发事件插话评估，周期循环也会检查已存会话。
- 普通主动插话不限制每天的钟点，受可选周末静默、直接回复冷却、主动发言冷却和新增人类消息门槛（默认 1 条即可评估，不强制凑 2 条）约束；模型评估可决定不说话；未回应的话题是否重复由上下文语义判断，不只比较话题字符串。无人回应时采用更长冷却。
- 梦境/日记有本地日期标记和补发窗口，优先于普通插话；它们保留独立配置窗口（包括日记 19:00 的显式窗口），遵循周末静默、冷却和新增活跃/语义批准。
- 日记由每日整理同批生成并保存，只有当天固定快照全部完成且日记非空才能发布；发送阶段不另做写作调用。尚未完成或没有内容时不标记已发，也不阻塞普通插话。
- 定时内容的语义判断明确针对本次发布：日记传入已保存正文，梦境传入分享意图；适合普通接话不等于适合此刻发布日记/梦境。
- 定时发布与普通插话都要求未评估的近期人类活动（默认 180 秒，不与维护心跳长度绑定）、冷却和语义参与批准；不是“24 小时内聊过就能发”。无活动或模型否决不冒充已发送；窗口内新活动仍可重新判断。已评估消息的否决水位持久化，重启不反复为旧消息调用模型。
- 时间使用配置中的固定 UTC offset，不是带夏令时规则的时区。日期边界、窗口和数值均以 [`settings.toml`](../../config/settings.toml)、[`config.py`](../../dafeiyu/config.py) 为准。
- 周期检查遍历所有已存会话，代码未按群聊/私聊类型排除；不要把自动发言描述成仅限群聊。
- GM 手动 `speak`、`dream`、`diary` 不经过上述自动触发门槛；手动梦境/日记默认不占用当日标记，除非指定 `mark`。
- GM `diary` 仅发送已保存的当日日记，无成品时返回 409，不立即触发整理或独立生成；关闭每日整理会停止新日记生成。

## 梗图与发送

- 梗图仅用于单条直接回复的 normal/reaction 模式；合批、自动发言和手动文本不自动附梗图。
- 候选必须通过已启用场景、用户原话证据、明确拒绝/安全排除条件等检查，再由语义复核决定语境是否合适；不再额外要求命中字面场景关键词；失败或超时只保留已发文字。
- 当前没有梗图时间冷却或回复间隔限制；不可因重复 tag 自行增加冷却。
- 对外发送成功后才记录 assistant 消息和相关状态；可选梗图失败不撤销成功文字。网络结果不明时不保证安全重发，见[架构边界](../../ARCHITECTURE.md)。

- 回归：[`test_conversation_policy.py`](../../tests/test_conversation_policy.py)、[`test_services.py`](../../tests/test_services.py)、[`test_meme_policy.py`](../../tests/test_meme_policy.py)、[`test_style.py`](../../tests/test_style.py)

离线测试验证控制流与规则；人设自然度、真实模型决策和群聊体验需另外验收。

每日整理同时产出记忆和日记草稿，发布与整理执行分离：安静群可整理已有新原文，但整理本身不会发消息。直接回复仍按平台 p2p/@ 元数据寻址；没有把角色名字的出现改成机械回复触发器。旧 `speaker_name` 回复字段兼容解析但不再写全局名字缓存，身份只由带证据的批次更新。
