# 大肥鱼角色视觉规范

目标：角色图、meme 和梦境中的大肥鱼是同一个鲸娘角色。亲近、心软的聊天人格保持不变，不引入外部仓库的台词或行为规则。

## 唯一规范与参考图

- 视觉规则保存在 [`persona.toml`](../../config/persona.toml) 的 `visual.prompt`，聊天上下文和梦境绘图共用；不要在不同提示词另写互相冲突的外观。
- [`character.png`](../../dafeiyu/web/character.png) 是无字全身角色图，同时用于管理工作台和梦境身份参考。
- 固定身份：宽圆脸、蓝眼睛、深蓝至青蓝长卷发、一根前弯呆毛、一对侧生鲸鳍耳、人形双臂双腿、单条自然连接的双叶鲸尾。
- **只有鲸鳍耳，没有人耳。** 鲸鳍耳位于头部两侧，是身体结构；禁止在其下方或旁边画出肉色耳廓、耳垂，也不能画成“人耳加鲸鳍发饰”。
- 项目固定使用藏青白色女仆装、白围裙及鲸形徽章，少量哑金装饰；场景插画约 2.8 头身，meme 约 2.1 头身。头身比例不改变角色年龄观感。
- 场景、动作、表情与镜头可以变化；发型、耳部、尾巴、服装识别点与清晰圆润的二次元画风保持稳定。

## 绘图与资产验收

梦境接口会同时传入固定视觉规范、本次场景和参考图。Gemini 使用图文 `generate_content`；OpenAI-compatible 使用带参考图的 `images.edit`，供应商与所选模型必须支持该接口。不再以纯文字生成替代参考图输入。图片调用失败沿用已有的文字发送行为，不表示图片通过验收。

meme 沿用 [`meme_corpus.toml`](../../config/meme_corpus.toml) 的文案与语义场景。替换时逐张检查：

1. 头部两侧无额外人耳，鲸鳍耳仍然存在；不能只靠“提示词写了”判定通过。
2. 发型、脸型、衣裙与鲸尾一致；尾巴数量、连接、四肢与道具接触正常。
3. 原动作、表情和文字含义保持；文字可读、无多字漏字。
4. 完整画面无意外裁切、水印或额外角色。

离线测试只验证请求包含规范与参考图，以及资产进入发布包；不能证明真实模型始终遵守耳部和其他解剖要求。

2026-10-28 已用内置 imagegen 修订角色图及全部 26 张 meme，并目视检查完整画面和头部细节。具体提示词、选中资产与 SHA-256 记录见 [`character-normalization.json`](../../assets/character-normalization.json)。比例是创作目标，未做骨骼测量；梦境运行时接口未做真实模型验收。
