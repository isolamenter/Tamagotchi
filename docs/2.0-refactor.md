## 后台设计

- 蓝白角色识别贯穿导航与头像。配色：海蓝 `#1769e0`、深海文字 `#18334d`、浅水背景 `#eef5fb`、白色 `#ffffff`、灰蓝 `#70879b`、状态绿 `#23826c`。
- 中文正文使用本机苹方／思源黑体，导航和标题保持紧凑；时间与标识使用等宽数字。无需远程字体与前端构建链。
- 左侧为会话列表，中间是可筛选的消息时间线／记忆，右侧为当前会话状态与投递操作。移动端改为单列分区。
- 核心是查看和操作具体会话，不堆砌统计卡片。创建时间、消息数和记忆数服务于会话识别。
- 发送前明确目标；操作期间锁定目标；会话切换和后台刷新不清空输入，不跳走滚动位置，不显示旧请求返回的新会话数据。
- 登录令牌通过管理请求头发送，不继续放在 URL 中。页面静态壳不包含聊天数据。
