## 自定义替换方式
最终文件为白底 PNG，1254 × 1254。完整生成提示词与参考说明保存在 [PROMPTS.md](PROMPTS.md)。运行目录只保留这六张最终图，不包含弃用初稿或第三方参考原图。

替换同名 `.png`（也支持 `.jpg`，PNG 优先）后需要重启进程，清除已有的内存 image_key 缓存。每个进程首次命中标签时读取图片并上传飞书，随后复用 image_key。

只偶尔在情绪明确的闲聊中配图；认真求助、倾诉、祝福和纠错时提示模型留空标签。主动插话、定时事件使用独立流程，本次静态梗图只接入直接回复。
