# 静态梗图资源库 (Meme Pack)

本目录保留大肥鱼的六张静态梗图资源。2.0 自动发送只开放 `eat_rice`、`slack_off`、`fat_defense`，其余三张保留文件但关闭自动触发。

六张图均已参考[原版角色图](https://aigengtu.com/zh/meme/303)，通过内置 image_gen 逐张修订并目视检查。固定蓝白女仆裙、荷叶边头饰、围裙、蓝色渐变长发、鲸鳍与鲸尾，只改变表情、动作、道具和配字。

## 自定义替换方式
最终文件为白底 PNG，1254 × 1254。完整生成提示词与参考说明保存在 [PROMPTS.md](PROMPTS.md)。运行目录只保留这六张最终图，不包含弃用初稿或第三方参考原图。

替换同名 `.png` 后需要重新核对图片与领域匹配规则，并重启进程以清除已有的内存 image_key 缓存。每个进程首次允许发送该标签时读取图片并上传飞书，随后复用 image_key。

只有本轮用户明确对机器人邀饭／投喂、邀请摸鱼或直接进行身材调侃，原文证据、完整句式与回复文字都通过对应图片校验时，才允许自动配图。转述、否定、第三方、多人合并或其他歧义均拒绝。相邻自动梗图还必须间隔至少 9 条纯文字直接回复和 5 分钟，状态从数据库成功记录恢复。认真求助、倾诉、祝福和纠错不自动配图；主动插话、定时事件同样不附自动梗图。详见[实施记录](../../docs/meme-frequency-fix-plan.md)。
